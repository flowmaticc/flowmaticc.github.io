1. Aceptación de los términos

Al descargar, instalar o utilizar la aplicación Plantillas Macro aceptas estos Términos y Condiciones y la Política de Privacidad.

Si no estás de acuerdo con alguno de estos términos, no debes usar la aplicación.

2. Descripción del servicio

Plantillas Macro es una aplicación de escritorio para Windows que permite expandir plantillas de texto (DOCX, ODT, TXT) en cualquier aplicación mediante un sistema de comandos con tecla detonante.

La aplicación funciona íntegramente de forma local en el equipo del usuario y no necesita conexión a internet para funcionar. Si hay conexión, solo la usa para comprobar si hay versiones nuevas del programa o de los paquetes de idioma.

Como complemento opcional, se ofrece la extensión de navegador flowmaticc Position Caret, de descarga gratuita desde Chrome Web Store.

3. Licencia de uso

Flowmatic te otorga una licencia de uso gratuita, no exclusiva e intransferible para utilizar Plantillas Macro en todos los dispositivos que quieras.

Está permitido:

  • Instalar y usar la aplicación en tantos equipos como necesites
  • Crear y organizar plantillas propias
  • Usar la aplicación con fines personales o profesionales, también dentro de una empresa

No está permitido:

  • Vender la aplicación o distribuir versiones modificadas de ella
  • Realizar ingeniería inversa o intentar descompilar el software
  • Presentar la aplicación como propia o eliminar las referencias a Flowmatic

Para compartir el programa con otras personas, enlaza a la página oficial de descarga en flowmaticc.github.io.

4. Precio

Plantillas Macro es gratuito, con todas sus funciones y sin límite de plantillas. No hay periodo de prueba, suscripción ni pagos.

Si en el futuro se ofreciera alguna modalidad de pago, se anunciaría con antelación y nunca se cobraría nada sin tu aceptación expresa.
